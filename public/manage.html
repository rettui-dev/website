Settings

These are the settings the node lets the website change. A service can be turned off here, but only turned on again in the terminal on the node. Saving asks in a pop-up for your password and your passkey or a code from your app.

Reticulum configuration

What the node's Reticulum config says, read only. Secrets and anything the node does not list are shown as set or not set, never with their value.

This node uses a shared Reticulum instance. The file shown here is this node's own config; the live settings may be those of another Reticulum process.

Change the Reticulum configuration

The node lets the website change a few Reticulum settings: transport, and for each interface whether it is enabled, its mode, announce cap, bitrate and ingress control. A change is tested before it is kept. Applying asks in a pop-up for your password and your passkey or a code from your app.

Reticulum restarts. The website then checks that it can still reach this node and keeps the change. If it can't within 5 minutes, the node puts the old config back by itself.

Restart Reticulum

Stops and starts the node's Reticulum network. Connections drop for a moment; the management listener stays up, so this page can still reach the node. The node allows one restart every 5 minutes.
