Join the network

Reticulum has no central server. You join by adding an interface to your own Reticulum, pointed at a node that is already part of the network. The rettui entry point is a node you can connect to over TCP:

rns.rettui.dev:4242

Host rns.rettui.dev, port 4242, TCP. If you can't connect, check that it is up.

Reticulum config file

This is for Reticulum itself (rnsd, or any program that starts its own Reticulum). Open its config file, by default ~/.reticulum/config. Reticulum uses the first of /etc/reticulum, ~/.config/reticulum and ~/.reticulum that has a config file. Find the [interfaces] line and add this below it, with the other interfaces:

  [[rettui entry point]]
    type = TCPClientInterface
    enabled = yes
    target_host = rns.rettui.dev
    target_port = 4242

The text between the double brackets is the name of the interface; Reticulum has no separate name setting, so you can call it anything. If your file has no [interfaces] line yet, add one above the block. Then restart Reticulum, and run rnstatus to see the interface and its traffic.

rettui

rettui keeps a Reticulum config of its own. Open the Reticulum tab (in the terminal UI or the web UI), add an interface, and pick a TCP client. Enter rns.rettui.dev as the host and 4242 as the port, make sure it is enabled, and save. Restart Reticulum from there to apply it. You can also edit the config as text and paste the block above. See the documentation for the details.

Sideband, Columba and MeshChat

These apps each have a place to add a Reticulum interface. Add a TCP client interface (some apps call it TCP Client, or TCPClientInterface), type rns.rettui.dev as the target host and 4242 as the port, and restart the app's Reticulum if it asks you to. Where that screen is differs between apps and versions, so look in their connectivity or interface settings. An app that lets you edit the Reticulum config as text takes the block above.

From an Android phone

Scan this with your camera or a QR scanner. It holds the same interface config as above as plain text, so you can copy it from the scanner and paste it into an app that takes a Reticulum config as text. Otherwise type the host and port by hand.

Other entry points

These work the same way, and you can add more than one. Use them if rns.rettui.dev is down, or to spread the load. The status page shows which ones are up.

  • front.rns.rettui.dev:4242
  • back.rns.rettui.dev:4242
  • side.rns.rettui.dev:4242
