Check a download

Compare the SHA-256 of the file you downloaded with the one listed under the file (the Copy button beside it copies it). Put the checksum and the file name in a file called SHA256SUMS, with two spaces between them, in the folder with the download:

sha256sum -c SHA256SUMS --ignore-missing

It prints OK for each file that matches. On macOS use shasum -a 256 -c SHA256SUMS; in Windows PowerShell use Get-FileHash <file> -Algorithm SHA256 and compare the result by eye. If the release has a SHA256SUMS file, you can download that instead. A checksum shows that the file is the one GitHub holds; it does not show who made it.
