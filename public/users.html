One-time password

It is shown only now, and never again. Give it to them in a safe way (in person, or in an end-to-end encrypted message). They must choose a new password when they sign in with it.

All users

Users from the config file are managed there: only their two-step sign-in can be reset here. The last admin cannot be removed or given another role. The password and two-step sign-in of an admin are only reset on the server, with scripts/users.js reset-password or reset-2fa, and another admin is only demoted or deleted there, with set-role or delete.
