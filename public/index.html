What it does

Terminal UI

Keyboard and mouse control, and 80×24 is enough.

Android app

The same client on your phone, with notifications you can reply from. Get the APK from the latest release.

Web UI

The same features in the browser (rettui --web). It works on phones and over slow links.

Written in Rust

Built on rsReticulum and rsLXMF, for Linux, Windows and macOS. It also runs in Docker.

Messaging and chat

LXMF conversations with any LXMF client, and RRC hubs, rooms and whispers.

NomadNet

Browse pages, or host your own node with a page editor and live preview.

Games

Play turn-based games with your contacts over LRGP, a move a message.

Sealed backups

Back up your identities and settings under a passphrase, and open them again with or without rettui.

Git repositories

Clone, browse and host Git repositories over Reticulum with rngit, from the Repos tab.
